# 🤖 Python Single DB RAG Assistant

## 📌 Project Overview

Python Single DB RAG Assistant is an AI-powered web application that demonstrates the implementation of **Retrieval-Augmented Generation (RAG)** using a **Single Knowledge Base**. The application enables users to ask Python-related questions in natural language and receive context-aware answers generated by an OpenAI Large Language Model (LLM).

Unlike a traditional chatbot that depends only on its pre-trained knowledge, this application first retrieves the most relevant information from a Python tutorial website using semantic search and then provides an accurate response based on the retrieved context.

This project is ideal for understanding how modern AI applications combine **Vector Databases**, **Embeddings**, **Semantic Search**, and **Large Language Models** to build intelligent question-answering systems.

```

                           ▼

                           │

               Load HTML Content
                           │

              Recursive Text Splitter
                           │
                           ▼
                Generate Embeddings
                           │
                           ▼
                 OpenAI Embedding Model
                           │
                           ▼
```

# 🌟 Why This Project?

Traditional chatbots answer questions based only on their pre-trained knowledge, which may lead to outdated or hallucinated responses.

This project addresses that limitation by retrieving relevant information from a trusted knowledge source before generating an answer. As a result, the responses are more accurate, context-aware, and grounded in the provided data.
